## Исправление

Пустой ввод отклоняется с HTTP 400 до обращения к AI. Корректный результат
проверяется в `server.mjs`: тема из разрешённого списка, черновик — непустая строка.
Ошибки, некорректный JSON/содержимое и ожидание AI дольше 300 мс дают HTTP 200
с `manual_review`, `topic: null`, `draft: null`.

Менеджер видит понятное сообщение о ручном разборе, исходная заявка сохраняется,
предыдущая тема и черновик очищаются. Устаревшие ответы и ошибки не перезаписывают
результат последнего запроса. Имитатор оставлен без изменений.

## Проверка

- `node server.mjs` — запуск страницы и API.
- `node --test triage.test.mjs` — HTTP-интеграция, все сбои имитатора,
  некорректный ввод/ответы, таймауты, очистка UI, ответы в обратном порядке.
- Node.js 24.22.3, без внешних зависимостей.
- Браузерная визуальная проверка пока не выполнена; сценарии перечислены в README.

## AI и самостоятельная проверка

Использован OpenAI Codex в ChatGPT для кода, тестов и документации.
Агент выполнил автоматические тесты и проверил их вывод. Кандидату перед отправкой
нужно самостоятельно просмотреть код, выполнить команды README и пройти
сценарии ручной проверки в браузере; их выполнение здесь не утверждается.

## Польза

Меньше ручного набора для типовых заявок и понятная обработка сбоев без старого
черновика; измерение — время работы на заявку, доля черновиков без исправлений
и частота ошибок до/после.
